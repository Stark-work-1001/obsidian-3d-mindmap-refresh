# 验收标准与验证记录

> 本文档记录**验收方法与通过标准**。具体机器的 vault 路径、性能采样、工具链细节
> 与任何本地调试痕迹都不进入仓库或发行包。

## 发布门禁

- `scripts/deploy.mjs` 校验 `manifest.json`、`package.json`、`versions.json`
  三者的版本元数据一致，并逐文件校验拷贝后的哈希。
- 发行包与源码包均不含设置数据（`data.json`）、临时目录（`_tmp/`）或 `node_modules/`。
  `scripts/package.py` 以白名单收件，并在打包后断言这些条件。
- 源码包可独立解包重建：由 Rust 源码重新编译产生的 `main.js`
  应与交付产物逐字节一致。
- 插件运行时不发起网络请求；安装与回滚只涉及本插件目录，不改动其它插件。

## 自动化测试

12 项自动化测试通过，其中 5 项直接驱动已构建的 WASM：

1. stride-four 内存布局，以及锚定节点与移动邻居相邻时的行为。
2. 3000 个重合坐标下八叉树细分安全终止。
3. 半径增大导致碰撞间距增大。
4. 弹簧静止长度变化改变几何并重新激活引擎。
5. 空图与越界边保持安全。

其余 7 项覆盖三种学习布局在 3000 节点下的表现、确定性、锚点保持、
尺度响应、整齐树／加权径向层级、3000 层深链、畸形环与碰撞间距。

## 应用内验收项

- 300 / 1200 / 3000 节点夹具能绑定到预期文件与节点数，Rust worker 就绪，
  坐标全部有限。
- 3000 个批渲染实例与 3000 个预期节点一一对应；连线批次保留层级与首层环状连线。
- 全部 23 种布局在 3000 节点夹具下坐标有限且保留全部渲染节点。
- 全局球径变更同时影响渲染球体与 Rust 碰撞半径；连线间距更新作用于当前 Rust 引擎。
- 选中点旋转、相机移动、全折叠（3000 → 20）与全展开（20 → 3000）均可用。
- 菜单名称与提示不溢出；键盘导航与 Escape 关闭可用。
- 明暗两种主题下均做视觉复核。
- 备注预览中公式正常渲染；别名内链保留 `目标#锚点` 而非显示别名。
- 重点节点变亮，且无光晕精灵、无选择外壳、无全屏 bloom。
- 自定义渐变对话框可打开、预览、应用、关闭并保存；单色模式生成纯色背景。
- 学习路径高亮的是真实祖先边，可禁用并恢复。
- 单节点半径覆盖在全局半径变更后保持不变。
- 3000 节点知识星座总览下，一级章节标签全部可见。

> 测试引入的状态会被清理，阅读设置被还原。不对用户笔记内容发起写入。
> 新增的 `learningPath` 默认值是有意的迁移行为。

## 性能参考

> 以下数字来自特定机器、特定夹具、特定视口与设置的采样，
> **不构成对其它 vault、相机或硬件的帧率承诺**。

| 场景 | 每帧绘制调用 | 分配的标签 DOM | 观测帧率 |
| --- | --- | --- | --- |
| 基线版本，3000 节点，已稳定 | 3015 | 3000 | 57–70 fps |
| Rust 计算中（球体放大、有选中节点） | 3 | 160 | 44–53 fps |
| 同上，计算结束 | 3 | 160 | 89 fps |
| 知识星座，3000 节点，已稳定 | 3 | 160 | 178–180 fps |

两次物理步进的 worker 读数约 6.8–7.4 ms。普通节点走两次绘制调用
（节点批次 + 连线批次），选中节点额外增加一次。

绘制调用与 DOM 数量的下降是直接测得的；帧率区间因布局、焦点与参数不同，
**不是受控加速比**。

## 已知边界

- 原始 TypeScript 源码已不可得。本工程是从已安装构建产物恢复的 JavaScript
  可读工程，加上若干新模块，并非丢失的原 TS 工程。
- 力导向模拟最多 600 tick 后停止，交互时显式重新激活；
  密集碰撞的邻域限制为每节点 96 个候选。
- 依赖旧版 bloom 或旧工具栏的诊断项属于历史记录，不是本次刻意变更后的验收标准。
- 本仓库与发行包均不包含任何 vault 内容、备份、凭据或本地调试产物。
