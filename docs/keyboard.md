# Keyboard and pointer reference

Shortcuts work while the map has focus (click the map once). They are ignored
while you type in a text field or compose text with an input method.

## Navigation

| Key | Action |
| --- | --- |
| ↑ / ↓ | Previous / next node in outline order (within the entered branch) |
| ← / → | Parent / first child |
| Letter or digit | Jump to the next node whose text starts with it |
| Ctrl/Cmd+Enter | Enter the selected branch |
| Escape | Step back: close a menu, leave Connect/Arrange mode, close search, leave the branch, clear the selection |
| Home | Overview (whole map) |
| Alt+← / Alt+→ | Back / forward in the navigation history |
| Shift+arrows | Rotate the view |
| Page Up / Page Down | Move closer / further |
| Ctrl/Cmd+F | Search nodes and notes; Enter / Shift+Enter step through matches |

## Editing

| Key | Action |
| --- | --- |
| Tab | Add a child (type the text, Enter to add, Escape to cancel) |
| Enter | Add a sibling |
| F2 | Rename |
| Shift+Enter | Edit the node's note (Ctrl+Enter saves, Escape cancels) |
| Delete / Backspace | Delete the node (larger branches ask first) |
| Space | Collapse or expand |
| + / - | Expand / collapse |
| ] / [ | Indent / outdent |
| Shift+Tab | Outdent |
| Alt+↑ / Alt+↓ | Move up / down among siblings |
| Ctrl/Cmd+Z | Undo |
| Ctrl/Cmd+Y, Ctrl/Cmd+Shift+Z | Redo |

While adding nodes, Enter keeps going with another sibling and Tab with a
child, so a list can be typed without touching the mouse.

## Pointer and touch

| Gesture | Action |
| --- | --- |
| Click | Select (a sphere under the pointer wins over a label drawn over it) |
| Double-click a node | Enter its branch (a leaf: show it in context) |
| Double-click empty space | Up one level, or the overview |
| Drag | Rotate (Arrange mode: drag a node to place it) |
| Right-drag, middle-drag, Shift+drag | Pan |
| Scroll | Move towards the pointer (or the rotation centre, see View → Camera controls) |
| Ctrl+scroll / trackpad pinch | Same, in finer steps |
| Alt+scroll | Magnify (narrow the field of view) without moving |
| Ctrl/Cmd+click | Open the note in the editor at that node |
| Mouse back / forward buttons | Navigation history |
| One finger | Rotate |
| Two fingers | Pinch to zoom, move to pan |
| Double tap | Same as double-click |

## Commands

All commands from 1.x keep their IDs, so existing hotkeys still work. New in
2.0: *Show the whole map*, *Go back*, *Go forward*. Search for "3D Mind Map"
in the command palette to see them all.
